## Como acessar e utilizar o Bar_TechStore

### 1. Iniciar o sistema

- Abra o arquivo `Bar_TechStore.jar`, caso esteja disponível.
- Aguarde a abertura da tela inicial do sistema.
- Certifique-se de que o MySQL esteja em execução para permitir a comunicação com o banco de dados.

### 2. Acessar o sistema

- Na tela de login, informe seu usuário e senha cadastrados.
- Clique no botão de entrar para acessar o sistema.
- Caso os dados estejam incorretos, confira as informações de acesso.

### 3. Navegar pelo sistema

Após entrar, utilize os botões disponíveis na tela principal para acessar as funcionalidades.

- **Clientes:** permite cadastrar, consultar, editar e excluir clientes.
- **Produtos:** permite acessar o gerenciamento de produtos.
- **Vendedores:** permite consultar os dados dos vendedores, conforme as permissões disponíveis.

### 4. Gerenciar clientes

Na tela de clientes:

- **Cadastrar:** preencha o nome e o telefone e clique em Cadastrar.
- **Listar:** exibe os clientes registrados.
- **Editar:** selecione um cliente na tabela, altere as informações desejadas e confirme em Editar.
- **Excluir:** selecione um cliente e confirme a exclusão.

### 5. Encerrar o sistema

Utilize a opção de saída disponível na interface ou feche a janela do programa.
